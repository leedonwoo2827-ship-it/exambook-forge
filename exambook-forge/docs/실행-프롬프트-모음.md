# 실행 프롬프트 모음 (회차별 · 과목별)

Claude Desktop(exambook-forge 플러그인)에서 **기출을 1회분씩 스캔하며 자사 회차를 증분 생성**할 때 쓰는 프롬프트.

- **규칙**: 기출 1회분 → 자사 3회차. 회차 번호는 `_rounds/`의 기존 회차 **다음부터 자동**,
  중복 회피는 "**이미 만든 자사 회차 전부**"와 대조하므로 반복해도 계속 안 겹침.
- 폴더 연결(Cowork) 후 아래 프롬프트를 붙여넣기. 첫 실행 시 "02·03·04·05에 씁니다" 1회 확인 → 승인.
- 두 경우:
  | 경우 | 책 폴더 | 테마 | 과목 | 문항/회차 | 산출 |
  |---|---|---|---|---|---|
  | **A. SQLD** | `D:\00work\ocr-output-260723` | `sqld`(파랑) | 2과목(10:40) | 50 → chunk10 = 5편 | 02·03·04·05(영상 포함) |
  | **B. 빅분기 필기** | `D:\00work\ocr-output-260730` | `teal` | 4과목(20씩) | 80 → chunk10 = 8편 | 02·03 (04·05 영상은 선택) |

- 웹(XAMpass) 소비 규약은 `references/exam-web-contract.md`, 개념 풀은 시험별 syllabus
  (`sqld-syllabus.md` / `bdae-written-syllabus.md`)를 스킬이 자동 참조한다.

## 참고
- **단계 분리 실행**: `/exam-all` 대신
  - `/exam-questions rounds=3 chunk=10 theme=<sqld|teal> book=<책>` (문제 02 + 영상 04·05)
  - `/exam-summary book=<책>` (기존 03 백업 후 전체 병합 요약)
- **웹만 필요**(빅분기 등): 02(문제)+03(요약)만 만들면 웹의 문제풀이·성적표·이론·게시판이 동작(`--src auto`).
  슬라이드/영상이 필요할 때만 04·05를 추가 생성(같은 번들 이름이라 재임포트 불필요).
- **한 번에 집필**: `rounds=21`(SQLD) / `rounds=9`(빅분기)로 몰아 돌리거나 위 회차 프롬프트를 순서대로.
- **슬라이드 룩**은 문항/대본과 독립 — 확정되면 `assets/slides/_deck.css`·`scripts/bundle.py`만 손봐서
  `bundle.py --book <책>`로 재번들만 하면 기존 회차도 새 룩 적용.
- **영상 렌더(#3)**: 번들(`05/<회차>/`)을 chodangi-mp4의 `render.bat` 위로 드래그하거나 `work\05\`에 복사 후
  `render.bat` 실행 → 음성·자막·카운트다운·합성 → `draft/<회차>.static.mp4`.
