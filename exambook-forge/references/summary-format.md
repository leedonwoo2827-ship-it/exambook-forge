# 요약원고(요약노트) 포맷

해설을 모아 **과목 → 대항목 → 상세**로 종합하고 **중복 내용을 정돈**한 학습 요약을 만든다.

**기본(primary) 산출물은 HTML** — 인라인 SVG·표·이론 시각화가 가장 잘 담기고 자기완결이기 때문이다.
MD는 동일 내용의 소스/경량본으로 병행한다. 둘 다 **추후 hwpx 변환**을 전제로 구조를 단순하게 유지한다.
- `03/summary_{subject}.html` ← **기본**
- `03/summary_{subject}.md`  ← 소스/경량본

## 소스
- 1차: `01/`의 `## 해설`(원본 기출 해설)
- 2차(선택): `02/`의 자사 문항 해설
- 각 요약 항목은 **어떤 문항에서 왔는지 출처(회차+번호)** 를 표기한다.

## 구조 (과목 → 항목 → 상세)

```markdown
# SQLD 요약노트 — SQL 기본 및 활용

## 1. 계층형 쿼리
### 1.1 기본 구조
- START WITH 로 시작 노드, CONNECT BY PRIOR 로 전개 방향 결정.
- PRIOR 자식=부모 → 순방향, PRIOR 부모=자식 → 역방향.
> 출처: 01-17, 01-18, 01-19 · 관련 자사: m01-12, m02-08

### 1.2 내장 함수
| 함수 | 의미 |
|---|---|
| LEVEL | 깊이 |
| SYS_CONNECT_BY_PATH | 전개 경로 |
| CONNECT_BY_ROOT | 최상위 값 |
| CONNECT_BY_ISLEAF | 리프 여부(1/0) |
> 출처: 01-20

## 2. 집합 연산자
...
```

## 정돈 규칙 (중복 제거)
- 동일 개념이 여러 문항 해설에 흩어져 있으면 **한 항목으로 통합**하고 출처를 모두 나열.
- 상충/보강되는 설명은 정확한 쪽으로 통일하고, DBMS 차이는 각주/표로 구분.
- 표로 정리 가능한 것(키 종류, 조인 종류, 계층함수, 윈도우 프레임)은 표로.
- 과목 순서는 시험 과목 순(1과목 → 2과목), 항목 순서는 `sqld-syllabus.md` 대분류 흐름을 따른다.

## SVG 도형 (요약·이론에 적극 사용)
- 요약/이론은 개념 시각화가 핵심이므로 **SVG를 많이 넣는다**(`svg-conventions.md` 규약).
- 저장: `03/assets/{개념slug}.svg`, 참조: 요약 MD/HTML에서 `![설명](assets/{slug}.svg)`.
- 좋은 후보: 조인 종류 벤다이어그램, 계층 트리, 정규화 1→2→3NF 흐름, 윈도우 프레임 구간,
  SQL 실행순서 흐름, 3층 스키마, 집합연산. 문항용 SVG(02/assets)를 재사용해도 좋다.
- HTML 출력에는 SVG를 **인라인**으로 삽입(외부 파일 의존 없이 자기완결)한다.

## 출처 표기
- 각 소절 끝에 `> 출처: {id}, {id} ...` 인용 라인. 자사 문항이 있으면 `· 관련 자사: {id}` 추가.
- 이는 compy-ui-mujejip `[5 요약노트]`의 "출처(회차+번호) 인용" 규약과 호환된다.

## HTML 출력 (기본 산출물)
- **자기완결 HTML**: 인라인 CSS, 표 스타일, **인라인 SVG** 포함, 외부 리소스/스크립트 없음.
- 한글 폰트/표 가독성 우선. **단순 시맨틱 마크업(h1~h4, table, ul, figure)** — hwpx 변환 친화.
- 구조는 MD의 과목→항목→상세와 1:1 대응(같은 내용, 표현만 HTML).

## hwpx 변환 경로 (나중)
- HTML → hwpx 변환을 전제로 마크업을 단순·표준으로 유지(복잡한 CSS 레이아웃·flex/grid·position 지양).
- **SVG는 hwpx가 직접 못 받을 수 있으므로**, hwpx 내보내기 단계에서 SVG를 PNG로 래스터화해 치환한다
  (`svg-conventions.md`의 `--rasterize-svg` 흐름 재사용). 변환 전 HTML/MD 원본은 SVG 유지.
- 표는 병합/중첩 없이 단순 행렬 구조로(hwpx 표 변환 안정).

## 파일

- `03/summary_SQL.html` / `.md`
- `03/assets/*.svg` (요약·이론 도형; HTML엔 인라인 삽입)
- (선택) `03/summary_index.html` — 두 과목 링크 모음
